# Software Engineering Gruppe 16

## Prosjektet:

Velkommen til Gruppe 16 sitt utviklingsprosjekt!
Vi har som mål til å utvikle en ny og bedre løsning til vår kunde Østfold Husflidslag (Nåværende løsning: https://husflid.no/lag/ostfold-husflidslag/#home)
Løsningen vår skal være en fullstendig nettside, med en front- og backend, påmeldingsfunksjon og administratorverktøy.

## Team:

Vi er 5 studenter fra Høgskolen i Østfold med erfaring fra to forskjellige linjer: Informatikk og Informasjonssystemer.

# Installasjon og Kjøring

## FORUTSETNINGER
Din maskin må ha MySQL workbench, JDK 25 eller nyere og Node Packet Manager klar for enklest mulig oppsett.

## STEG 1

Last ned prosjekt på maskin, Høyreklikk på frontend filen og velg "Open in integrated terminal" og skriv "NPM install"

## STEG 2

Bruk SQL filer til å sette opp SQL server i din lokale SQLWorkbench, bruk også insert fil til å fylle database med data. HUSK: Bruk Localhost 3306 og bytt passord til 1234 på SQLworkbench eller bytt passordet i DatabaseRepository.
ELLER
Kjør opp Dockeren ved å skrive >run i søkefeltet på VScode

## STEG 3

Høyreklikk på frontend filen og velg "Open in integrated terminal" og skriv "NPM run dev"
